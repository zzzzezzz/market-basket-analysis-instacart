# Dataset Instructions

The Instacart Market Basket Analysis dataset is not included in this repository because of its size and the original Kaggle competition's data-access terms.

## Download

1. Visit the [Instacart Market Basket Analysis competition on Kaggle](https://www.kaggle.com/competitions/instacart-market-basket-analysis/data).
2. Sign in to your Kaggle account.
3. Accept the competition rules if prompted.
4. Download the dataset and extract the archive.
5. Copy the following six CSV files into this directory:

- `orders.csv`
- `order_products__prior.csv`
- `order_products__train.csv`
- `products.csv`
- `aisles.csv`
- `departments.csv`

After downloading, the directory should contain all six files.

**Note:** The raw CSV files are excluded from Git tracking. Do not commit or push them to this repository.
